# Solar Frontier - Initialization and Startup

## Game Description

Solar Frontier is an interactive 3D space simulation where players can explore a dynamically generated solar system. The game features celestial bodies like planets, moons, comets, and asteroid belts, along with space stations and NPC ships engaging in trade and transport. Players can observe the simulation, interact with objects, access station markets, and manage cargo and passengers.

## How to Start the Game

To run Solar Frontier, you need to use the provided Python development server. This ensures that all game assets and modules are served correctly.

1.  **Run the Python Server:**
    Open your terminal or command prompt, navigate to the project's root directory (`d:\PROJECTS\HTML\Solar Frontier`), and execute the following command:
    ```bash
    python serve.py
    ```
    This will start a local HTTP server, typically on port 8000. You should see a message in the terminal indicating the server is running, for example: `Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...`

2.  **Open the Game in Your Browser:**
    Once the server is running, open your web browser (e.g., Chrome, Firefox, Edge) and navigate to the following address:
    [http://localhost:8000/Solar Frontier 3.html](http://localhost:8000/Solar%20Frontier%203.html)

    Alternatively, if the server started on a different port, use that port number instead of `8000`.

This will load the game, and you should see the main menu. From there, you can start a new game, visit the hangar, or access settings.
